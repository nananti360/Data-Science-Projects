# TITLE: UNSUPERVISED NETWORK INTRUSION DETECTION SYSTEM USING ISOLATION FOREST

# ABSTRACT AND PROJECT OVERVIEW

Network Intrusion Detection Systems (NIDS) are critical defense mechanisms designed to identify malicious activity and unauthorized access across modern computing infrastructure. Traditional signature-based detection models struggle against novel threats ("zero-day" attacks) because they rely on pre-existing attack signatures. To address this limitation, this project implements an unsupervised machine learning approach using the Isolation Forest algorithm.

By operating in an unsupervised capacity, the Isolation Forest model models baseline network behavior using normal or mixed traffic from a training dataset, isolating anomalies based on how quickly data points can be partitioned within decision trees. Because anomalous network intrusions typically possess distinct feature profiles compared to normal traffic, they require fewer random splits to isolate, making this algorithm uniquely efficient for high-dimensional network telemetry.

The implementation methodology for an unsupervised Network Intrusion Detection System using Isolation Forest follows a structured, multi-stage machine learning pipeline that progresses from raw data preparation to model deployment and evaluation. The pipeline begins with data ingestion and preprocessing, where separate training and testing datasets containing network telemetry—such as protocol types, network flags, service ports, packet durations, and flow volumes—are cleaned and transformed. Categorical attributes undergo numerical encoding, while continuous features are normalized or standardized to ensure balanced feature weight during tree splitting. Following preprocessing, an Isolation Forest model is instantiated and fit on the training dataset without relying on labeled target classes. The algorithm operates on the principle that anomalous network intrusions are rare and structurally distinct from normal traffic, requiring fewer recursive decision-tree splits to isolate and resulting in shorter path lengths near the root nodes. A contamination hyperparameter is configured during training to reflect the expected baseline proportion of anomalous activity. Finally, the trained model is deployed onto the unseen test dataset to generate decision scores and binary anomaly classifications, with detection performance systematically measured using precision, recall, F1-score, and confusion matrix analytics to evaluate how accurately malicious intrusions are identified relative to benign network traffic.
